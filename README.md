# Scientific Calculator in Python 🧮

A simple yet powerful Scientific Calculator built with Python to handle both basic arithmetic and advanced mathematical calculations.

## Features ✨
* **Basic Arithmetic:** Addition, Subtraction, Multiplication, Division.
* **Scientific Functions:** Trigonometry (sin, cos, tan), Logarithmic calculations, Powers, Square roots.
* **Math Constants:** Support for Pi ($\pi$) and Euler's number ($e$).

## How to Run 🚀

1. **Prerequisites:** Make sure you have Python 3.x installed on your computer.
2. **Clone the repository:**
   ```bash
   git clone [https://github.com/tga30012008-create/Scientific-Calculator-Python.git](https://github.com/tga30012008-create/Scientific-Calculator-Python.git)

 * Navigate to the folder:
   cd Scientific-Calculator-Python

 * Run the application:
   python calculator.py
